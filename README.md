# ATL Skills — разработка

Мод для Minecraft 26.3 + NeoForge. Тестовая версия: до проверки в настоящей игре не использовать на основном мире.

Отдельные навыки игрока: кирка, топор, лопата, мотыга и меч. Дерево — 1, камень — 5, медь — 10, железо — 15, золото — 20, алмаз — 30, незерит — 50. Прогресс общий для предметов каждого типа, сохраняется после смерти. Требование действует на ванильные инструменты, на модифицированные предметы пока не распространяется. Опыт добычи даётся за разрушение блоков инструментом, опыт меча — за победу над мобами.

Требуемый уровень ограничивает использование и получение результата из верстака, инвентарного крафта и кузнечного стола. Творческий режим исключён. Мод не блокирует автоматические крафтеры и другие моды для создания предметов. Мод должен быть установлен на сервере и у игроков. Перед тестами сделайте резервную копию мира.

Меню навыков открывается клавишей K (можно изменить в управлении). При повышении уровня появляется уведомление. Требования видны в подсказках ванильных инструментов.

Стол показывает ванильные чары, подходящие предмету; конфликтующие и уже установленные затемнены, проклятия исключены. Прокрутка — колесом мыши. Жёлтое число — необходимые книжные полки, зелёное — стоимость уровнями игрока; также нужен один лазурит. Число полок и стоимость проверяются сервером. Удача, Добыча и ряд других сильных чар требуют 25 полок; Острота требует 10 полок и 10 уровней. Для остальных чар требования зависят от редкости, для брони сохранены прежние. Творческий режим освобождён от стоимости. Описание показывается при наведении.

Чары получают опыт отдельно на каждом предмете при использовании, вызывающем износ. Удерживайте Shift над предметом, чтобы увидеть прогресс и оставшееся количество. Для обычных чар на броне нужны 20 использований для I → II и 40 для II → III; для прочих предметов — 300 и 600. Более редкие чары требуют в 2–4 раза больше. Уже сохранённый опыт не сбрасывается. Одноуровневые чары не прокачиваются. Одну версию мода нужно установить и на сервер, и каждому игроку.
